# Kept separate from the event environment because the two cannot

#   numpy         events need 1.26 (OpenEB ABI), akida pulls 2.1

# Create with:
#   python -m venv C:\tmp\akida\venv
#   C:\tmp\akida\venv\Scripts\Activate.ps1
#   pip install -r requirements-akida.txt
#
# On Colab and Kaggle the runtime python is too new for the TF 2.19
# wheel, so every notebook builds a python 3.11 venv first:
#   !apt-get install -qq python3.11 python3.11-venv python3.11-dev
#   !python3.11 -m venv /content/akv
#   !/content/akv/bin/pip install -q akida-models==1.14.2
#
# And every command there needs MPLBACKEND=Agg, because Colab's inline
# matplotlib backend is not valid inside the venv and TF imports
# matplotlib on the way up.
